# Резервная копия компонентов дизайн-системы

Копия репозитория [`iiko-DS/DS`](https://github.com/iiko-DS/DS): компоненты (web и mobile), организмы, токены, стили, спецификация и подключатель `connect.js`. Снимок от **08.10.2026**.

## Что можно сделать

- **Работать с ДС, когда основной репозиторий недоступен** — брать компоненты, токены и подключатель из этой копии и раздавать компоненты локально, пока доступ не вернётся.
- **Восстановить систему целиком** — из этой копии, если понадобится.
- **Обновить копию** — вручную, по необходимости.

## Правило

По умолчанию всё работает так, как описал Андрей: прототипы подключают ДС из публичного репозитория одной строкой ([`../подключение-ds.md`](../подключение-ds.md)). Если дизайн-система недоступна — компоненты берём из этой копии.
