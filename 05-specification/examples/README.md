# Примеры к шагу 5

Примеры результата шага: файлы — копии вложений с вики, чтобы шаг был воспроизводим без доступа к вики.

## Что можно сделать

- **Взять пример PRD как ориентир формата** — `rekvizity-yurlica-zakazchika.prd.md` (PB-5671).
- **Воспроизвести прототип из примера** — `rekvizity-prototype-prompt.md` (промпт для другой LLM).
- **Посмотреть сам прототип** — `yur-lico-rekvizity_16.html` (автономный файл, открывается локально).
