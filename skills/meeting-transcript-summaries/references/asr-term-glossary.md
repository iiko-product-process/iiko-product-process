# Расшифровки авто-ASR: типовые искажения (звонки iiko, русская речь)

Наблюдалось на расшифровках звонков («Расшифровка собрания», 30–50 мин, 3+ спикеров): помимо очевидных
ошибок распознавания, ASR **режет окончания фраз, склеивает реплики разных спикеров и теряет слова** —
поэтому смысл восстанавливается по контексту, а не по букве.

## Проверенные соответствия

| В расшифровке | Что на самом деле |
|---|---|
| «гид», «в гид», «этот гид» | гит-репозиторий (git) |
| «эко вэб», «э к в», «ай к в», «и. Kb», «vaber», «viber», «шапка ИК» | iiko web |
| «фильма», «в фильме», «макеты в фильме» | Figma |
| «в с коды», «в коти», «в с к/в коти» | VS Code / ИИ-ассистент в редакторе (по контексту) |
| «скела», «скелаха», «скотч папок» | скилл, структура папок скилла |
| «блогер / мажор / минор / инфо» | blocker / major / minor / info (шкала критичности) |
| «дипсиг», «дипсик», «лепсик» | DeepSeek |
| «клот», «скилл для клота» | Claude |
| «чаджи 5», «чат JPT», «чат GPT» | ChatGPT |
| «мир», «в миру», «дать гермесу доступ к миру» | Miro |
| «мермей шаблон», «мермейд» | mermaid (диаграммы) |
| «эгоизд», «ягаис», «е г и с», «э г а и с», «егэса» | ЕГАИС (алкогольная отчётность) |
| «погинатор», «генатор», «агинатором», «тогинатор» | пагинатор |
| «сайт нарф», «сайт бар» | сайтбар (боковое меню) |
| «гэпы» | gaps (токены отступов) |
| «мадалка» | модалка |
| «конп», «компо» | комбо |
| «вебкал центр», «веб кц», «колцентр» | веб-колл-центр |
| «сборщик», «файл-сборщик» | реальный артефакт сборки прототипа (НЕ искажение — не «исправлять») |
| «Дядя богатые» (прощание) | «Давайте, богатые» |
| «Мхм», «Угу», «Ага» | филлеры-поддакивания, выкидывать |

Чужие имена, роли и названия продуктов ASR калечит особенно охотно — сверяй по `references/iiko-team-roster.md`,
а термины из выжимки сабагента подтверждай по исходнику (см. `references/delegating-long-transcripts.md`).

## Что оставлять как есть

Слова, для которых контекст не даёт однозначной замены, **не додумывай**: «тайски» (=?), «антисуда доктрин» (=?),
«приказ об изменении трескурента» (=?), «посылки» (=?), «максим пикс» (=?), «Швечкин» (=?), «макетики» (=?).
Либо оставляй в кавычках как в транскрипте, либо помечай `[?]` — выдуманная расшифровка дороже пропуска.
Проверено на практике: красивое «ЕГИС/ЭГОИС» из чужой выжимки оказалось ЕГАИС, а достройка
«комбо (первое и второе)» в источнике отсутствовала — обе правки пришлось откатывать.

## Обязательная оговорка в ответе

Одной строкой в начале: «расшифровка автоматическая, местами с ошибками распознавания; термины восстановлены
по контексту: «гид» = гит-репозиторий, «эко вэб» = iiko web, «в с коды» = VS Code». Без неё пользователь
принимает искажения за твои ошибки в понимании материала.

## Таймкоды

Расшифровка приходит репликами `Имя Фамилия  12:34`. Таймкоды полезны, чтобы найти «то, что обсуждали в конце»
(план действий обычно идёт в последней трети встречи).

В зависимости от артефакта:

- **Итоги встречи в чате / файл «Итоги_встречи_…»** — таймкоды не нужны, если пользователь не просил.
- **Заметка `kind: транскрибация` в vault** — таймкоды давай в заголовках тематических блоков
  (`## 2. Пагинатор: исследование (3:18–8:08)`): так уже сделаны соседние заметки в `Транскрибации/`,
  и по ним удобно находить место в записи.
