# Входящие заметки → Markdown-база

Пользователь кидает в топик «Заметки» (или просит сохранить заметку/договорённость/транскрибацию) текст или файл.
Задача: конвертировать в аккуратный .md и сохранить в базу **$HERMES_HOME/ARTIFACTS/** (Obsidian-совместимая, корень = vault).

## Формат файла

Каждая заметка — один файл `{год}/{месяц}/{ГГГГ-ММ-ДД}_{slug}.md` с frontmatter:

```markdown
---
title: Краткое название
date: ГГГГ-ММ-ДД
kind: заметка            # заметка | договорённость | транскрибация | встреча | идея | файл
category: Категория      # см. таблицу раскладки ниже
topic: Тема              # опционально: короткая тема/проект/человек → подпапка
tags: [тег1, тег2]
source: telegram
---
```

## Раскладка по смыслу (категоризация)

Структура должна РАЗВИВАТЬСЯ САМА. Каждая заметка раскладывается по категории и теме:

| kind | category (папка) |
|---|---|
| транскрибация | `Транскрибации` |
| договорённость | `Договорённости` |
| встреча | `Встречи` |
| идея | `Идеи` |
| заметка | `Заметки` |
| файл / неясно | `Прочее` |

- `category` — ставишь из таблицы (или из смысла, если точнее: договорённость по проекту → всё равно `Договорённости`).
- `topic` — определяешь из содержания: имя/ проект/ направление (например `Руслан`, `маркетплейс`, `iiko-разметка`). Файл ложится в `Категория/Тема/`. Если темы нет — просто `Категория/`.
- Файл САМА папка создаётся скриптом `notes_classify.py` — тебе нужно лишь корректно заполнить frontmatter (kind, category, topic). **Не строй папки вручную.**
- Если не уверен в теме — не указывай topic, положим в корень категории.

Правила:
- slug — транслит или короткое осмысленное имя (латиница/дефисы).
- Для **договорённостей** обязательна секция `## Решения` с буллетами
  `- [ ] Ответственный: … · Срок: ГГГГ-ММ-ДД · Суть: …` — по ней ищут «что на ком висит».
- Для **транскрибаций** — таймкоды и реплики спикеров, если различимы; в конце секция «Суть и решения».
- Связывай с похожими заметками вики-ссылками `[[2026/09/…]]` (Obsidian).
- Русский текст сохраняется как есть (UTF-8).

## Конвертация файлов

| Вход | Действие |
|---|---|
| текст в сообщении | тело заметки (выдели главное, структурируй заголовками) |
| .md / .txt | нормализовать + frontmatter |
| PDF / docx / xlsx / pptx | извлечь текст (навыки pdf/docx/xlsx/powerpoint/ocr-and-documents), переложить в md; при сложной вёрстке — сохранить и оригинал |
| фото (скрин/доска) | распознать текст vision-моделью; если нечитаемо — сохранить файл в raw/ и честно сказать |
| голосовые | транскрибация пока НЕ настроена: сообщи, предложи записать текстом |
| ссылка на видео встречи | youtube-content, если доступно |

Оригиналы файлов (не-md) сохраняй в `raw/` (`raw/{ГГГГ-ММ-ДД}_{имя}`) — для сверки.

## После сохранения

1. **Раскладка по категории**: `python3 $HERMES_HOME/ARTIFACTS/.index/notes_classify.py`
   (класс. по frontmatter kind/category/topic; сам создаёт подпапки и перекладывает файл).
2. Пересборка индекса: `python3 $HERMES_HOME/ARTIFACTS/.index/notes_index.py` (FTS5 + index.md) — он же автоматически коммитит и пушит.
3. Ответь КОРОТКО, одной строкой:
   `✅ Заметка: «{title}» · {category}/{topic?} · {путь}` (и пару слов, если что-то не удалось распознать).

## Pitfalls

- Приём вложений ботом проверен — если файл не пришёл/битый, попроси переслать.
- **NFD-имена (macOS).** Файлы из desktop-вложений приходят в Unicode-нормализации NFD: `read_file` и python по NFC-имени («Дейли») файл НЕ находят (`FileNotFoundError`). Ищи так:
  `[n for n in os.listdir(dir) if unicodedata.normalize('NFC', n).startswith('Дейли')]` — и работай с найденным именем.
- **Если `read_file` пишет «Binary file»** на .docx/.md — извлеки текст вручную:
  `zipfile.ZipFile(f).read('word/document.xml')` → `re.findall(r'<w:p[ >].*?</w:p>', xml, re.S)` → склей `<w:t>` внутри параграфа (сохраняет разбивку по строкам, включая таблицы). Проверь также `word/footnotes.xml`, `header*/footer*` — текст может лежать там.
- **`read_file` может считать валидный UTF-8 файл «бинарным»** (плотный не-ASCII текст, длинная расшифровка) — и на .md, и после санитайза control-символов. Не бейся в него: выведи текст через `terminal` python-ом кусками (`print(t[21000:42000])`), как в остальных случаях.
- Не сохраняй служебный текст переписки — только саму заметку/договорённость.
- Не придумывай содержание; неоднозначности уточняй одним вопросом.
- Если контента мало (пустое сообщение/непонятный файл) — переспроси, что сохранить.
