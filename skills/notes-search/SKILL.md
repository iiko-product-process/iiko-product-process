# Поиск по базе заметок (дешёвый по токенам)

Пользователь спрашивает что-то, что может лежать в его заметках («что решили по X?», «когда встреча?», «что за договорённость с N?»).
База: **$HERMES_HOME/notes/** (Obsidian-совместимый md, корень = vault). Поиск — индексами, БЕЗ чтения всех файлов.

## Порядок (от дешёвого к дорогому)

0. **Синк с Mac**: `git -C $HERMES_HOME/notes pull --ff-only` (тихо; ошибки игнорируй — например, нет сети). Чтобы правки, сделанные пользователем на Mac, тоже находились.
1. **Оглавление**: если вопрос «о чём вообще есть» — прочитай `$HERMES_HOME/notes/index.md`
   (одна строка на заметку: дата, название, kind, теги) — этого хватает для навигации.
2. **FTS5-поиск**: `python3 $HERMES_HOME/notes/.index/notes_search.py "<запрос>" [лимит]`
   - запросы: слова (AND по умолчанию), `OR`, `"фраза"`, поля: `title:слово`, `kind:договорённость`, `tags:…`;
   - возвращает файл + сниппет совпадения. Лимит по умолчанию 8.
   - Если «индекс не найден» — сначала `python3 $HERMES_HOME/notes/.index/notes_index.py`.
3. **Точечное чтение**: если сниппетов мало/мало контекста — прочитай 1–3 подходящих файла
   (`read_file` по путям из поиска) и ответь по ним.
4. Итоговый ответ — кратко, со ссылкой на файл(ы): `(заметка: 2026/09/…md)`.

## Правила экономии токенов

- Никогда не читай всю папку заметок «на всякий случай» — только индекс или FTS.
- Не пересказывай заметку целиком — отвечай на вопрос пользователя.
- Если совпадений нет — так и скажи; предложи уточнить запрос (OR/синонимы).

## Pitfalls

- index.md/notes.db устаревают, если новая заметка сохранена без пересборки — тогда запусти notes_index.py.
- Пути файлов — как вернул поиск (относительно $HERMES_HOME/notes).
