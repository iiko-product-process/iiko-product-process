# Hermes wiki: хранилище артефактов задач

Всё, что сотрудник создаёт по задаче — карточка проблемы, гипотезы, Story, PRD, прототипы, транскрипты
встреч, выгрузки, презентации — живёт в **ARTIFACTS** (Hermes wiki). Репозиторий процесса хранит только скиллы и
правила; артефактов в нём нет.

**Когда использовать:** первый запуск (вики ещё нет), «сохрани в задачу», «где лежит артефакт по задаче»,
нужно завести новую задачу или показать структуру.
**Когда не использовать:** поиск по старым заметкам — `notes-search`; быстрая заметка «на подумать» —
`notes-inbox`; артефакт нужно отдать в общий слой — `share-to-common`.

## Где лежит ARTIFACTS

`ARTIFACTS` — отдельная папка в дереве, **не внутри notes/** (notes — только заметки):

1. `IIKO_ARTIFACTS`, если задан;
2. `~/.hermes/iiko-artifacts-root` (путь сохраняется при первой настройке);
3. `$HERMES_HOME/ARTIFACTS` или `~/ARTIFACTS` — если папка уже есть;
4. иначе — **спросить пользователя**, где хранить, и сохранить выбор в `~/.hermes/iiko-artifacts-root`.

Путь по умолчанию не прошивается: у каждого своя машина.

## Структура

```
<ARTIFACTS>/
  index.md                     оглавление: задачи, статусы, ссылки
  _шаблон/                     пустой каркас задачи
  <слаг>/
    README.md                  карточка: статус, текущий шаг, кто ведёт, ссылки
    журнал.md                  дата · что сделали · артефакты · кто
    01-проблема/               02-гипотезы/      03-требования/   04-дизайн/
    05-спека/                  06-реализация/    07-пилот/
    материалы/                 встречи/
```

Создать каркас одной командой:

```bash
bash scripts/wiki-init.sh "$IIKO_ARTIFACTS"                       # index.md, _шаблон
bash scripts/wiki-init.sh "$IIKO_ARTIFACTS" --task pb-7105-nacenka  # ещё и новая задача
```

## Правила

- Одна задача — одна папка `<ARTIFACTS>/<слаг>/`; второй папки «на всякий случай» не заводим.
- Каждый артефакт — Markdown с шапкой: дата, задача, шаг, автор. Имя файла — по содержимому,
  без «новый файл 2».
- Крупные файлы (прототипы, xlsx, pdf) кладутся в раздел шага рядом с описанием, а не в корень вики.
- Встречи — в `встречи/`: протокол отдельно, исходный транскрипт отдельно.
- Карточка задачи (`README.md`) обновляется при переходе шага: статус, ссылки, следующий шаг.
- В репозиторий артефакты не переносятся. Если наработка нужна всем — `share-to-common`.

## Связка с другими скиллами

| Ситуация | Скилл |
|---|---|
| завести задачу, разложить файлы, вести журнал | `task-workspace` |
| быстро сохранить мысль вне задачи | `notes-inbox` |
| найти что-то в вики | `notes-search` |
| перенести готовые файлы из рабочей папки в задачу | `task-workspace` → `sync-task.py` |
| отдать наработку в общий слой | `share-to-common` |

## Проверка

- `ls "<вики>/artifacts"` показывает `_шаблон` и папки задач;
- в `index.md` есть строки по задачам со ссылками;
- у новой задачи есть `README.md`, `журнал.md` и семь разделов шагов.
