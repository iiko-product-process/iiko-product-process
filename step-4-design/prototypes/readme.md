# Прототипы — инструменты

Копия корня репозитория [`iiko-DS/Prototypes`](https://github.com/iiko-DS/Prototypes) (снимок от 08.10.2026) — всё, чем прототипы собираются и показываются. Живой источник — там же; правила и рецепты — в [гайде](../).

## Что можно сделать

- **Взять живой пример страницы-прототипа** — `demo-connect.html`: ДС подключается одной строкой, хедер и сайднав приходят сами.
- **Показать прототип «как на устройстве»** — тач-режим и корпуса: тап вместо ховера, подсказки долгим нажатием, системные полосы телефона/планшета.
- **Сравнить размеры компонентов** — `ds-sizes-toggle.js`: переключатель «Компоненты: Mobile / Desktop» на одном кадре.
- **Не терять мобильную ширину при переходах** — `ds-frame-nav.js`: ширина кадра сохраняется при переходах между страницами.
- **Собрать панель ревью стенда** — `layouts.js`: реестр экранов и шагов стенда.

## Что здесь лежит

| Файл | Для чего |
|---|---|
| `demo-connect.html` | живой пример страницы: ДС подключается одной строкой, хедер и сайднав приходят сами, контент — динамический контейнер |
| `touch-mode.js`, `touch-mode.css`, `touch-hover-off.css` | тач-режим: тап вместо ховера, подсказки — долгим нажатием, протяжка = прокрутка |
| `device-chrome/` | корпуса устройств (телефон / планшет / десктоп): системные полосы — статусбар и навбар |
| `ds-frame-nav.js` | сохраняет ширину кадра при переходах между страницами (мобильный пресет не сбрасывается на десктоп) |
| `ds-sizes-toggle.js` | переключатель «Компоненты: Mobile / Desktop» на одном кадре |
| `layouts.js` | реестр панели ревью (`ds-review.js`): экраны и шаги стенда — пример для своего проекта |

Подключение ДС — одной строкой из публичного репозитория: [`../подключение-ds.md`](../подключение-ds.md). Если дизайн-система недоступна — компоненты берём из [`../ds-backup/`](../ds-backup/).
