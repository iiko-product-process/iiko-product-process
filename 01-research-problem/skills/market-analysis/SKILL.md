# Анализ рынка

Действие исследования: понять **рынок вокруг проблемы** — игроков, аудиторию, объём, УТП, точки роста — чтобы выбирать концепцию на данных. Методика — по обезличенному эталону: `01-research-problem/examples/primer-issledovaniya/`.

## Состав анализа (по эталону)

1. **Топ игроков** — ранжирование по трафику: веб — списки категории на SimilarWeb; мобайл — топы App Store / Google Play (скринами). Топ-10 + оговорки (VPN, пираты, зеркала — честно отмечать, где статистика искажена).
2. **Аудитория сервисов** — MAU и платящие пользователи по годам; у каждой цифры — источник и год. Показывать динамику и причины (уход сервисов с рынка, сделки, подписки-агрегаторы).
3. **Математика оценок** — где прямой статистики нет, считать **bottom-up с явными допущениями**. Пример из эталона: визиты пиратских сайтов (48 млн) ÷ визитов на пользователя (2,8) ≈ 17,1 млн пользователей. Формулу и допущения писать в текст.
4. **TAM / SAM / SOM** (подход эталона):
   - **TAM** = население − те, кто с малой вероятностью платит (в эталоне: минус дети до 15 лет — 26,9 млн, и 70+ — 13,4 млн → ≈ 106,6 млн);
   - **SAM** = те, кто может платить с комфортом (в эталоне: 55% относят себя к среднему классу → ≈ 58,6 млн; источник доли обязателен);
   - **SOM** = фактическая аудитория игроков (свой сервис + конкуренты + пиратские).
5. **УТП игроков** — по каждому 1–2 строки: на чём выигрывает (удобство и фичи, звук, эксклюзивы, бесплатность).
6. **Точки роста** — вывод: какие фичи/подходы перенять, где возможности; это вход для решений по концепции.

## Правила

- Каждая цифра — ссылка + год; оценки помечать как оценки и указывать метод расчёта.
- Допущения писать явно (в эталоне даже самокритично: «статистика источника слишком подозрительная — сделаем допущение 50%»); сомнительное — «сомневаемся» / «проверить».
- Проценты из опросов без выборки не принимать как факт («информации про выборку нет, поэтому сомневаемся»).
- Расхождения источников показывать, а не усреднять молча.
- Динамика важнее статики: как менялось по годам и почему.

## Формат результата

Разделы: **Топ сервисов → Аудитория → TAM/SAM/SOM → УТП → Точки роста** + сводная таблица находок (`показатель | значение | источник | дата | метод`). Сохранить в `tasks/<слаг>/01-проблема/исследования/анализ-рынка.md` + строка в журнал.
