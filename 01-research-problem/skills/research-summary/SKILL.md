# Итог исследования

Финальное действие: собрать результаты (интервью, ю-тесты, рынок, данные, артефакты других скиллов) в **краткий итог с выводами** — для решения: развилка шага 1 / выбор концепции / следующий шаг. Структура — по обезличенному эталону (`01-research-problem/examples/primer-issledovaniya/notion-страница.md`).

## Перед итогом

Убедиться, что зафиксированы **цели исследования** (в эталоне на каждую встречу: «Цель интервью — узнать…», «По результатам нужно понять: 1)… 2)…»). Выводы пишутся **по целям**, поэтому без них итог не собрать.

## Структура итога (по эталону)

1. **Контекст и цели** — что исследовали, зачем, какие вопросы проверяли (1–3 строки + список целей).
2. **Что сделали** — методы и охват: N интервью (кого, сегменты), ю-тесты, данные, рынок.
3. **Выводы по целям** — по каждой цели: что услышали/увидели; примеры и цитаты респондентов; подтвердилась или нет.
4. **Общие наблюдения** — что заметили вне целей (сквозные паттерны: например, «возраст влияет на стиль пользования»).
5. **Рекомендации/улучшения** — списком, каждая привязана к цели; честно фиксировать и неподтверждённое (в эталоне: «соцсеть — минус :(»).
6. **Дальше** — открытые вопросы, следующие шаги/исследования.

## Правила

- Кратко: не пересказ интервью, а сжатые выводы; детали — ссылками на выжимки.
- Факты отделять от интерпретаций; каждая рекомендация — из данных.
- Не подгонять под ожидания: не подтвердилось — так и написать.
- Результат: `ARTIFACTS/<слаг>/01-проблема/исследования/итог-исследования.md` + короткое сообщение + строка в журнал; по итогу — решение по развилке (координатор `problem-validation`).
