# Скорость загрузки страниц (PagePerformance): метод и базовые цифры iiko

Класс задач: «посчитай среднюю скорость загрузки», «какие страницы её увеличивают», «почему тормозит экран X».
Плагин PagePerformance установлен в iiko-инстансе (ядро Matomo 5.x), API-модуль `PagePerformance`, UI — Поведение → Производительность страниц.

## Как считать (проверено 08.10.2026)

1. **Общая средняя** за период:
```
POST /index.php  module=API&method=PagePerformance.get&idSite=1&period=range&date=2026-10-01,2026-10-07&token_auth=…
```
Поля (все **в секундах**): `avg_time_network`, `avg_time_server`, `avg_time_transfer`, `avg_time_dom_processing`, `avg_time_dom_completion`, `avg_time_on_load`, `avg_page_load_time`.

2. **По страницам с компонентами** — `Actions.getPageUrls` + `flat=1&filter_limit=-1` со столбцами:
`showColumns=label,nb_hits,nb_hits_with_time_on_load,avg_page_load_time,avg_time_network,avg_time_server,avg_time_transfer,avg_time_dom_processing,avg_time_dom_completion,avg_time_on_load`
(усреднять по `nb_hits_with_time_on_load`, а не по `nb_hits` — замер есть не у каждого хита).

3. **Кто «поднимает» среднюю** — не сортировать по времени страницы: страницы с 200 хitов и 3 с не влияют. Считать **вклад**:
`вклад = nb_hits_with_time_on_load × (avg_page_load_time_страницы − средняя_по_сайту)` — в секундах «сверх среднего»; доля = вклад / Σ положительных вкладов. Порог объёма ≥200 загрузок, иначе шум.
Скрипт: **`$HERMES_HOME/scripts/page_speed.py`** (печатает общую среднюю, топ-20 по вкладу, топ-20 самых медленных с компонентами, разрезы по разделам и устройствам; править константы W1/W2 внутри).

4. **Устройства**: `PagePerformance.get` с сегментом `deviceType==desktop|smartphone|tablet`. Мобильные обычно хуже в 1,3–2 раза.

## Как читать результат (что писать в ответе)

1. Сначала цифру и её динамику к прошлой неделе, потом состав по компонентам.
2. «Виновников» подавать по вкладу, а не по абсолютному времени; указывать долю вклада.
3. Причину группировать: **DOM-обработка/завершение** (клиентский рендер, тяжёлые бандлы, списки/OLAP) vs **сеть** (доставка файлов: бандл, кэш, CDN — при быстром сервере 0,06–0,07 с) vs сервер (у iiko почти всегда не он).
4. Отдельной строкой — мобильные (там те же экраны хуже в 1,3–2 раза).

## Питфоллы

- Значения возвращаются **в секундах** (0.82 = 0,82 с), не в миллисекундах и не в «условных» единицах.
- Усреднять только по `nb_hits_with_time_on_load`: при усреднении по `nb_hits` цифра занижается.
- `period=range` для PagePerformance работает (метрики — средние, агрегируются корректно), но для сверки по неделям лучше брать Пн–Вс диапазонами одинаковой длины.
- Поле `label` в `Actions.getPageUrls` — путь без хоста; для «какой ресторан тормозит» нужны сегменты `pageUrl=@<host>` (по одному хосту за раз).
- В отчёте «по заголовкам» страницы сливаются (общий `document.title` модуля), поэтому виновников искать по URL.
