# Аудит «фича вышла — приходят ли события»: окно дат и новые категории

Проверено на iiko prod 18.11.2026 (кейс CSI/NPS).

## Главная ловушка: окно дат

Проверка «закинули события CSI/NPS, есть ли результаты» была сделана по диапазону
`2026-01-01,2026-10-22` — вернулось 0 совпадений по `csi|nps|satisf|promoter|csat|feedback|опрос|оценк|рейтинг`.
Вывод «событий нет» был **неверным**: окно заканчивалось за месяц до выкатки. По диапазону,
доходящему до сегодня (`2026-11-11,2026-11-18`), события нашлись сразу.

Правило: при вопросе «вышло ли / приходит ли» диапазон всегда `<начало>,<сегодня>`. Если ответ
«нет данных» — сначала переспросить окно, и только потом говорить «не приходит».

Второй слой задержки: агрегаты (в т.ч. отчёты Events) читают архив, который пересчитывается по
порогу ~15 мин или по крону, — свежие события появляются в отчёте не мгновенно
(см. `report-freshness-and-archiving.md`).

## Новая фича = новая категория событий

Список категорий сам показывает выкатки. Октябрь 2026: `Session`, `Employees Schedule`, `Marketplace`.
Ноябрь 2026: добавились `AI Assistant` и **`Survey`** (CSI/NPS). Сверять `Events.getCategory`
до/после релиза, а не искать только по знакомым именам действий.

## Провал в действия категории

```
Events.getCategory            -> найти label, взять его idsubdatatable
Events.getActionFromCategoryId&idSubtable=<idsubdatatable>
```

На iiko в `Survey` оказались только три действия:

| Действие | Визитов | Событий |
|---|---:|---:|
| `csi_support_cancel` | 6 | 6 |
| `nps_product_cancel` | 1 | 2 |
| `nps_product_rate` | 1 | 1 |

Нет ни «показа опроса», ни «оценка отправлена». Такой набор нельзя читать как воронку —
это неполная разметка (видно отмены, не видно показов и завершений). В ответе писать явно:
«часть шагов воронки не размечена», и просить у разработки полный список событий.

## По дням

`period=day` по одному дню за вызов (цикл по датам) — надёжнее, чем multi-date ответ:
структура бывает и списком, и словарём, и содержит пустые дни. Кейс: `Survey` впервые 15.11
(2 визита / 3 события), затем 18.11 (6/6), между ними пусто — то есть фича включалась волнами
или это тестовые прогоны; без дневного разреза этого не видно.
