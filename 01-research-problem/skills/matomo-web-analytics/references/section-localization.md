# Локализация разделов и страниц: таблица «URL → русское название»

Класс задач: «сделай таблицу всех разделов и страниц с локализацией», «свяжи раздел с заголовком страницы».
Прогон-эталон: iiko prod, 14.10.2026, период данных 01–13.10.2026. Скрипты: `$HERMES_HOME/scripts/localization_table.py`,
`localization_md.py` (пакет в `$HERMES_HOME/exports/localization/`).

## Источники имён — по приоритету

1. **Локализация из репозитория продукта (истина)** — `client/**/i18n|locale|l10n|translat*.json`.
   Папки с Mac в контейнер не видны и вложениями-папками не приходят → **просить ZIP файлов локализации**:
   ```bash
   cd ~/Downloads/iikoWeb-develop
   find client -type f \( -iname "*.json" -o -iname "*.ts" \) | grep -iE "i18n|locale|lang|translat|l10n|ru" | head -40
   find client -type d \( -iname "*i18n*" -o -iname "*locale*" -o -iname "*l10n*" -o -iname "*translat*" \) -print0 \
     | xargs -0 zip -r ~/Desktop/iikoweb-locales.zip
   ```
   До получения архива — не выдавать свою интерпретацию URL за локализацию продукта.
2. **Заголовки страниц из Matomo** (`document.title`, как его ставит приложение) — рабочий суррогат, но покрытие частичное.
3. **Имена из URL** — только как черновик и с явной пометкой «предположительно».

## Рецепт: URL → заголовок из журнала Matomo

- По каждому модулю выбрать выборку визитов: `Live.getLastVisitsDetails&period=day&date=<день>&segment=pageUrl=@/<модуль>&filter_limit=40`,
  `showColumns="actionDetails"` — в каждом действии есть `url` и `pageTitle` (4 дня на модуль достаточно).
- Агрегация: нормализовать URL (убрать `/index.html`, query, `#`), в Counter по `pageTitle`; игнорировать пустые,
  `Page Name not defined`, `iikoWeb`. Заголовок страницы = самый частый непустой.
- Список страниц брать из `Actions.getPageUrls&flat=1&filter_limit=-1` (за тот же период), затем join по нормализованному URL.
- Раздел: RU-имя = самый частый заголовок с кириллицей среди его страниц; EN/тех. = самый частый без кириллицы.
- 75 модулей ≈ 200 с в фоне; сам сегментный `Actions.getPageTitles` с `pageUrl=@/<модуль>` НЕ использовать для привязки
  к модулю — сегмент фильтрует визиты, а не просмотры, и в ответ попадают заголовки чужих модулей (в /inventory протекал Purchase).

## Реальность покрытия (iiko, 01–13.10.2026)

- 501 страница, 75 разделов; **русские заголовки нашлись у 116 страниц и 19 разделов** — приложение проставляет
  локализованный `document.title` не везде. У остальных в данных «Inventory», «Purchase», «Till shifts», «Nomenclature»,
  «Page Name not defined» — это НЕ локализация, а техзаголовок; в ответе честно указывать покрытие и запрашивать репозиторий.
- Что удалось подтвердить данными: `/inventory` → «Инвентаризация», `/purchase` → «Заказы поставщику»,
  `/external-menu` → «Внешнее меню», `/lite-stock` → «Входящие заказы», `/integration` → «Источники заказов»,
  `/forecast` → «Выручка», `/customer-screen` → «Кампании», `/delivery-map` → «Карта доставок»,
  `/site-constructor` → «Конструктор сайтов», `/menu-quick` → «Быстрое меню», `/schema-editor` → «Отделения»,
  `/import-tool` → «Импорт данных», экраны call-center → «Создание заказа», `directories/accounts-transactions` → «Счета и проводки»,
  `internal-couriers/couriers` → «Заказы», `lite-stock/incoming-orders/order/:id` → «Входящие заказы».

## Тупики разведки (не повторять)

- **Локали JSON по стандартным путям нет**: `/assets/i18n/ru.json`, `/assets/locale/ru.json`, `/i18n/ru.json`,
  `/assets/locales/ru-RU.json` → 404; в `index.html` и `main-*.js` кириллицы нет (ленивые чанки, хешированные имена).
- **`<модуль>/ru-RU/index.html` — не файл локализации, а переключатель**: 166-байтная страница
  `localStorage.setItem('iikoWeb_language','"ru_RU"')` + редирект на тот же путь без `/ru-RU`. Язык выбирается клиентом.
- Значит: не раскапывать бандлы — сразу просить у пользователя файлы локализации из репозитория.

## Формат выдачи (что просит пользователь)

- CSV c «;» и UTF-8 BOM: `page_url; page_title; title_samples; visits; hits` и `module; ru_name; en_name; hits; visits; ru_variants`.
- Читаемый MD: три таблицы — разделы; топ-150 страниц по просмотрам; все страницы с русскими заголовками.
  Пользователь прямо просит «пришли md файлом» для таких таблиц; имя файла — с датой периода данных (ISO).
- В ответе: короткая выжимка (топ разделов с RU-именами), честная строка про покрытие локализации, запрос архива локализации
  с готовыми командами find/zip.
