# Задачи

Папка задач продуктового процесса iiko: **по папке на каждую задачу**. Все заметки, артефакты и вся история работ по задаче хранятся здесь — в одном месте, по единой структуре.

## Что можно сделать

- **Завести задачу** — агентом (рекомендуется): скажи «начинаем задачу …» — скилл `task-workspace` скопирует `_шаблон/`, заполнит карточку и журнал, закоммитит. Или вручную: `cp -r _шаблон <слаг>`, заполни `README.md` и первую строку `журнал.md` (слаг — латиницей, короткий, без дат).
- **Вести работу по шагам** — артефакты раскладываются по разделам: `01-проблема/` … `07-пилот/`; каждое действие — строкой в журнале.
- **Сложить входные материалы** — `материалы/` (презентации, документы, выгрузки) и `встречи/` (заметки и выжимки встреч).
- **Посмотреть историю** — карточка, журнал и git: кто, что и когда делал по задаче.

## Что должно получиться в итоге

Папка задачи со всей историей и артефактами — по единой структуре:

```
<слаг>/
  README.md        карточка задачи: что за задача, статус, текущий шаг, кто ведёт, ссылки
  журнал.md        история работ: дата · что сделали · артефакты · кто
  01-проблема/     шаг 1 — сигнал, карточка проблемы, валидация (+ исследования/ — интервью, данные, конкуренты, бенчмарки)
  02-гипотезы/     шаг 2 — снапшоты списков, решения по приоритизации, оценки
  03-требования/   шаг 3 — Story / продуктовые требования, брифы
  04-дизайн/       шаг 4 — макеты, прототипы, дизайн-ревью
  05-спека/        шаг 5 — PRD / спецификация для разработки
  06-реализация/   шаг 6 — сопровождение, приёмка
  07-пилот/        шаг 7 — пилот, запуск, метрики
  материалы/       входные файлы: презентации, документы, выгрузки
  встречи/         заметки и выжимки встреч по задаче
```

## Состав папки

| Путь | Что это |
|---|---|
| `_шаблон/` | Шаблон новой задачи — копируется при старте задачи |
| `skill/SKILL.md` | Скилл `task-workspace`: заводит папку задачи, раскладывает артефакты по разделам, ведёт историю |

## Скилл `task-workspace` (установка для команды)

1. Скопируй `skill/SKILL.md` в папку скиллов Hermes:
   - Linux/macOS: `~/.hermes/skills/productivity/task-workspace/SKILL.md`
   - Windows: `C:\Users\<логин>\AppData\Local\hermes\skills\productivity\task-workspace\SKILL.md`
2. Перезапусти Hermes или открой новую сессию.
3. Защити от автоочистки: `hermes curator pin task-workspace`.

В рабочем контейнере скилл уже установлен: `/opt/data/skills/productivity/task-workspace/`.

## Правила

- Живые данные сервисов (например, списки гипотез в прототипе шага 2) остаются в своих шагах; в папке задачи — снапшоты, решения и ссылки на них.
- Ничего из папки задачи не удаляется без явного согласия.
- Каждое действие — строка в журнале; после изменений — коммит и пуш.
- Секреты и персональные данные в папку не кладём; файлы больше 10 МБ — только с подтверждения.
