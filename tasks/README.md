# Личное пространство (ветка personal)

Эта ветка — твоё личное рабочее пространство. Здесь хранишь артефакты своих задач.

## Завести задачу

```bash
cp -r tasks/_шаблон tasks/моя-задача
```

Структура задачи: `01-проблема` → `02-гипотезы` → `03-требования` → `04-дизайн` → `05-спека` → `06-реализация` → `07-пилот` + `материалы`, `встречи`, `журнал.md`.

Правила ведения задачи — скилл `task-workspace` (на ветке `main`, `tasks/skill/`).

## Важно

- Эту ветку НЕ пушить в общую репу — она личная, живёт только в твоём форке.
- Обновления скиллов — через `main` (см. `CONTRIBUTING.md` на ветке `main`).
