## Суть

Разобрать, как на самом деле устроены пользовательские пути в iiko web: какие процессы и циклы устойчивы,
где работа обрывается, кто эти пользователи и какие процессы разрезаны между разделами. Итог — общий отчёт,
сырые данные для проверки и 22 гипотезы улучшений с отсылкой к конкретным цепочкам экранов.
