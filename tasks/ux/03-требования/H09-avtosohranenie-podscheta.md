## Цель

Не терять введённые количества при уходе из подсчёта и давать быстро продолжить с той же зоны.

## AS-IS

- 1 038 из 2 202 визитов (47,1%) заканчиваются в зонах подсчёта; 818 из 2 016 визитов с зонами не доходят до списка.
- Цикл «подсчёт ↔ зоны» повторяется 4–5 раз; 1 268 + 1 107 + 786 визитов в топ-цепочках.
- На мобильном обрыв 55,4% против 39,9% на компьютере; 53,1% всех обрывов — мобильные.

## TO-BE

- Введённые количества и позиция сохраняются автоматически (после ввода/перехода между зонами).
- При возврате — баннер «Продолжить с зоны N» и кнопка «Начать заново».
- Видно, когда сохранено («Сохранено в 14:32»), есть ручное «Сохранить».
- Конфликт версий/параллельный подсчёт — понятное сообщение, без потери данных.
- Черновик не влияет на финальные количества до завершения.

## Пользовательский путь

```text
Инвентаризация → подсчёт → зоны
└─ действие: ввод количества
   └─ элемент: автосохранение + статус
      └─ цель: не потерять введённое
         ├─ далее: уход → возврат → «Продолжить с зоны N»
         └─ альтернатива: «Начать заново» → очистка черновика
Возврат в подсчёт
└─ действие: открыть инвентаризацию
   └─ элемент: баннер продолжения
      └─ цель: быстро вернуться к работе
         └─ далее: та же зона/позиция
```

## Сценарий (Given / When / Then)

**Дано:** Пользователь ввёл часть количеств в зонах и ушёл из подсчёта.  
**Когда:** Он возвращается в ту же инвентаризацию.  
**Тогда:** Данные сохранены, показан баннер «Продолжить с зоны N», можно продолжить или начать заново.

## Критерии приёмки

- Введённые количества сохраняются после ухода/перезагрузки.
- При возврате виден баннер «Продолжить с зоны N» с номером зоны.
- «Начать заново» очищает черновик только после подтверждения.
- Статус сохранения виден; ошибка сохранения не скрывается.
- Параллельный подсчёт/конфликт версий обрабатывается без потери данных.
- Финальные количества не меняются от наличия черновика.

## Где проявляется

Инвентаризация → подсчёт → зоны. Главный мобильный проблемный сценарий: доля обрыва 55,4% на мобильном против 39,9% на компе; проверять на телефоне.
