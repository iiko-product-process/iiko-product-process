## Цель

Не отправлять пользователя в отдельный раздел интеграций: привязка источника заказов должна завершаться в контексте правки меню.

## AS-IS

- 4 419 визитов с правкой меню; только 625 (14,1%) доходят до привязки источника.
- 323 из 779 визитов привязки (41,5%) заканчиваются на её экране.
- Переходы «меню → интеграции» — 346, «редактор → интеграции» — 311, «меню → интеграции → адаптер» — 295, «меню → интеграции → адаптер → редактирование» — 214 визитов.
- 95,8% обрывов внешнего меню — с компьютера; доля обрыва на компе и мобильном почти равна (71,6% / 72,1%).

## TO-BE

- В редакторе меню есть шаг/панель «Источник заказов»: видно, привязан ли источник, и можно привязать его без ухода в «Интеграции».
- Для сложных настроек — ссылка «Расширенные настройки» в интеграции, но базовый сценарий завершается на месте.
- После привязки статус обновляется сразу; ошибки объясняются человеческим языком.
- Пользователь не теряет несохранённые правки меню при переходе.

## Пользовательский путь

```text
Внешнее меню → редактор меню
└─ действие: правка/публикация меню
   └─ элемент: панель «Источник заказов»
      └─ цель: привязать источник и опубликовать
         ├─ далее: статус «привязано», меню активно
         └─ альтернатива: «Расширенные настройки» → интеграции
Если источник не привязан
└─ действие: попытка опубликовать
   └─ элемент: предупреждение + CTA «Привязать»
      └─ цель: не оставить меню неактивным
         └─ далее: привязка в панели
```

## Сценарий (Given / When / Then)

**Дано:** Пользователь правит внешнее меню и у меню ещё нет источника заказов.  
**Когда:** Он публикует меню или открывает шаг публикации.  
**Тогда:** Видит статус привязки и может привязать источник в панели редактора, не уходя в интеграции.

## Критерии приёмки

- В редакторе меню виден статус «источник привязан / не привязан».
- При отсутствии привязки публикация показывает предупреждение и CTA «Привязать источник».
- Базовую привязку можно завершить без перехода в раздел «Интеграции».
- «Расширенные настройки» открывают интеграции с сохранённым контекстом меню.
- Несохранённые правки меню не теряются при открытии панели.
- После привязки статус обновляется без перезагрузки; ошибки понятны.

## Где проявляется

Внешнее меню → редактор меню → панель источника; переходы в интеграции. Проверять на компьютере (95,8% обрывов).

## Зависимости

| Команда / функционал | Серв | К кому обратиться |
|---|---|---|
| Меню/публикация | да | команда меню |
| Интеграции/источники заказов | да | команда интеграций |
| Права на источники | да | бэкенд прав |

## Out of Scope

- Полный редизайн экрана интеграций.
- Массовое копирование меню — H05.
- Статус публикации — H04 (связанная стори).

## Что нужно уточнить у PO

1. Какие источники можно привязывать в панели, а какие требуют полного экрана интеграций?
2. Нужна ли привязка на уровне меню или точки?
3. Что считать «опубликовано» и можно ли публиковать без источника?
