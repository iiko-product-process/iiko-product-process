## Цель

После повторного входа возвращать пользователя туда, где сессия прервалась, а не на главную/профиль.

## AS-IS

- По агрегированным переходам после логина пользователи чаще всего попадают на `/navigator/home` (2 492 перехода), `/user-profile` (878), `/forecast` (436), `/purchase/order-list-v2` (402).
- Исходный экран не восстанавливается: работа в карточке заказа, зонах подсчёта или ЦПУ прерывается.
- 1 108 визитов заканчиваются на логине; часть — посреди рабочего сценария.
- Из 2 130 пользователей с логином 1 080 (50,7%) хотя бы раз логинились после рабочего экрана; у 974 был следующий экран. Из 835, кто логинился не с главной и у кого был следующий экран, **76,9% ни разу не вернулись на тот же экран**, 72,9% — в тот же раздел; 55,0% при первом таком разлогине попали на главную.

## TO-BE

- Перед редиректом на логин сохраняется намерение (route + безопасные параметры).
- После успешного входа — возврат на этот route; если он недоступен/небезопасен — на главную с пояснением.
- Восстанавливаются фильтры/вкладки, если они были в URL; действия, требующие подтверждения, не повторяются автоматически.
- Работает для deep links и для истечения сессии на экране.

## Пользовательский путь

```text
Рабочий экран (карточка заказа / зоны подсчёта / ЦПУ)
└─ действие: сессия истекла
   └─ элемент: редирект на логин + сохранение намерения
      └─ цель: вернуться туда же после входа
         ├─ далее: тот же экран с прежним контекстом
         └─ альтернатива: экран недоступен → главная + сообщение
Прямая ссылка на объект
└─ действие: открыть без сессии
   └─ элемент: логин
      └─ цель: попасть на объект после входа
         └─ далее: объект или «нет доступа»
```

## Сценарий (Given / When / Then)

**Дано:** Пользователь работает на глубоком экране и сессия истекает.  
**Когда:** Он входит снова.  
**Тогда:** Система возвращает его на тот же экран; если экран недоступен — на главную с понятным сообщением.

## Критерии приёмки

- Deep link на карточку заказа → логин → после входа открывается та же карточка.
- Истечение сессии в зонах подсчёта → логин → возврат в ту же зону/подсчёт.
- Истечение сессии на дашборде/ЦПУ → возврат на тот же экран.
- Если объект удалён/нет прав — главная + сообщение, без цикла редиректов.
- Сохраняются только безопасные параметры; повторные опасные действия не выполняются автоматически.
