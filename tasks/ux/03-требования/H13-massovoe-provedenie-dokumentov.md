## Цель

Проводить несколько документов за одну операцию с предварительной проверкой и понятным результатом по каждому.

## AS-IS

- 709 из 1 166 визитов раздела (60,8%) заканчиваются на рабочем экране.
- Документы открывают и проводят по одному; 204 визита — цепочка «Документы → списание → списание → id».
- Ошибки видны только после открытия каждого документа.

## TO-BE

- В списке документов — множественный выбор и действие «Провести».
- Перед проведением — предпроверка: какие документы можно провести, какие нет и почему.
- Результат по каждому документу: успешно/ошибка; ошибки сгруппированы.
- Можно повторить только для неуспешных; действия логируются.
- Права: проводить можно только доступные документы.

## Пользовательский путь

```text
Документы → список
└─ действие: выбрать 2+ документа
   └─ элемент: «Провести»
      └─ цель: закрыть пачку
         ├─ далее: предпроверка → результат по каждому
         └─ альтернатива: отмена → статусы не меняются
Ошибка в части документов
└─ действие: повтор
   └─ элемент: список ошибок
      └─ цель: дожать без повторного выбора
         └─ далее: повтор только неуспешных
```

## Сценарий (Given / When / Then)

**Дано:** В списке есть несколько непроведённых документов.  
**Когда:** Пользователь выбирает их и нажимает «Провести».  
**Тогда:** Видит предпроверку, подтверждает, получает результат по каждому документу.

## Критерии приёмки

- Массовое проведение доступно для 2+ документов.
- Перед проведением показывается предпроверка (можно/нельзя + причина).
- После — результат по каждому; ошибки не скрываются.
- Можно повторить только для неуспешных.
- Недоступные документы блокируются.
- Действие логируется (кто, какие документы, результат).

## Где проявляется

Документы → список. 85,0% обрывов — компьютер; проверять на компе.
