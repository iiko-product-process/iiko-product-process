## Цель

Заменить ручной повтор одной и той же правки меню/цен на нескольких точках массовым копированием с предпросмотром.

## AS-IS

- Цикл «меню → редактор → меню» — 2 070 визитов, 7 249 вхождений; «редактор → меню → редактор» — 1 904 визита, 6 624 вхождения.
- Пользователь повторяет одно и то же действие по точкам вручную.
- Ошибки копирования не видны до публикации.

## TO-BE

- В меню/прайсе есть действие «Копировать в точки»: выбор целевых точек, предпросмотр различий, применение.
- Можно копировать меню целиком или выбранные разделы/цены (уточнить).
- Перед применением — diff: что добавится/изменится/удалится.
- После применения — отчёт по точкам: успешно/ошибки; можно повторить для неуспешных.
- Права: копировать можно только в доступные точки.

## Пользовательский путь

```text
Внешнее меню / прайс-лист
└─ действие: «Копировать в точки»
   └─ элемент: выбор точек + предпросмотр diff
      └─ цель: применить одну правку на несколько точек
         ├─ далее: отчёт по точкам
         └─ альтернатива: отмена → ничего не меняется
Ошибка на одной точке
└─ действие: повтор
   └─ элемент: список ошибок
      └─ цель: дожать без повторного выбора
         └─ далее: повтор только для неуспешных
```

## Сценарий (Given / When / Then)

**Дано:** Пользователь настроил меню/цены на одной точке и хочет перенести на несколько.  
**Когда:** Он выбирает «Копировать в точки» и подтверждает.  
**Тогда:** Видит diff, применяет к выбранным точкам и получает отчёт по каждой.

## Критерии приёмки

- Копирование доступно для 2+ точек за одну операцию.
- Перед применением показывается diff (добавление/изменение/удаление).
- После применения — результат по каждой точке; ошибки не скрываются.
- Можно повторить только для неуспешных точек.
- Копирование в недоступную точку блокируется.
- Действие логируется (кто, куда, что).

## Где проявляется

Внешнее меню/прайс-лист; 7 249 вхождений цикла. Проверять на компьютере.

- Синхронизация с внешними каналами.
