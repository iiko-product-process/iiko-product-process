## Цель

При возврате из карточки заказа сохранять фильтры, сортировку, вкладку и позицию скролла списка.

## AS-IS

- 2 175 визитов — цикл «список → карточка → список», 21 527 вхождений.
- 1 774 визита — повторный вход в карточку после списка.
- Пользователь возвращается в список и заново настраивает фильтры/прокрутку.

## TO-BE

- При открытии карточки состояние списка сохраняется в URL/сессии.
- Возврат (кнопка «Назад», хлебные крошки, браузер) восстанавливает фильтры, сортировку, вкладку и скролл.
- Deep link на карточку не ломает состояние; после возврата — тот же список.
- Если фильтры больше не дают результата — понятное пустое состояние, а не сброс.

## Пользовательский путь

```text
Список заказов (фильтры/скролл)
└─ действие: открыть карточку
   └─ элемент: карточка заказа
      └─ цель: правка
         ├─ далее: «Назад» → тот же список с фильтрами и скроллом
         └─ альтернатива: deep link → карточка без контекста списка
Возврат из карточки
└─ действие: назад
   └─ элемент: восстановленное состояние
      └─ цель: продолжить с того же места
         └─ далее: следующая карточка
```

## Сценарий (Given / When / Then)

**Дано:** Пользователь настроил фильтры/прокрутил список и открыл карточку заказа.  
**Когда:** Он возвращается в список.  
**Тогда:** Фильтры, сортировка, вкладка и позиция скролла восстановлены.

## Критерии приёмки

- После возврата из карточки фильтры и сортировка сохраняются.
- Позиция скролла восстанавливается (или явно предлагается «к тому же месту»).
- Работает кнопка «Назад» браузера и внутренняя кнопка возврата.
- Deep link на карточку не затирает сохранённое состояние списка.
- Пустой результат фильтра объясняется, без молчаливого сброса.

## Где проявляется

Закупки → список заказов / карточка. Проверять на компьютере и мобильном (42% визитов).
