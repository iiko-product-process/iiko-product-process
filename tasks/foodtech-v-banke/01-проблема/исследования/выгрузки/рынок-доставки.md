## 4. Чего НЕ найдено (проверялось, результата нет)

- Комиссии агрегаторов для ресторанов в % — в этой выгрузке не подтверждено (закрыто в выгрузке по ресторанной стороне и отчёте Data Insight).
- Доли рынка по доставке еды из ресторанов между Яндекс Едой, Самокатом, Купером, Ozon, «ВкусВилл», «Магнит» — не подтверждено; есть только доли рынка готовой еды ритейла (Sostav).
- MAU сервисов доставки — не найдено (закрыто в выгрузке по банкам частично: Яндекс Go 53,2 млн).
- История консолидации (уход Delivery Club в 2022, сделка «Яндекс»/Сбер, покупка «Самоката») — не подтверждено источником в этой сессии, требует добора.
- Прогнозы роста рынка ресторанной доставки до 2030 — не найдено.
