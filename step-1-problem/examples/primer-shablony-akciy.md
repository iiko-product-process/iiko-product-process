# Пример карточки: «Шаблонные акции» (из постановки шага 1)

> Пример-образец для формата. Числа взяты из постановки шага и **требуют проверки** по реальным источникам.

**Статус:** черновик
**Сегмент:** пользователи, работающие с шаблонами акций
**Источник сигнала:** постановка шага 1 (пример)
**Дата:** —

## 1. Формулировка
Мы видим, что сейчас шаблонами акций пользуются 70% пользователей, но при этом запускают рассылки по шаблонным акциям только 35% пользователей. Это может ухудшить успешность запущенных шаблонных акций и увеличить отток пользователей.

## 2. As-is / To-be
- As-is: шаблон создан, но рассылка по нему не запускается.
- To-be: шаблон доходит до рассылки — без ручных шагов, которые сейчас теряются.

## 3. Что уже известно и откуда
- 70% пользуются шаблонами, 35% запускают рассылки — постановка шага 1 — нужно проверить в аналитике.

## 4. Данные (план проверки)
| Метрика | Что проверяем | Источник | Статус |
|---|---|---|---|
| % пользователей с шаблонами | подтвердить 70% | Matomo / дашборды | нужно проверить |
| % запустивших рассылку по шаблону | подтвердить 35% | Matomo (воронка «шаблон → рассылка») | нужно проверить |
| Где отваливаются | шаги воронки, сегменты (новые/старые) | Matomo, сегменты | нужно проверить |

- Направление 2: автоматизация — плановый запуск по шаблону.
- Направление 3: обучение/подсказки на шаге запуска.
