# Бенчмарки: где искать UX-паттерны (шаг 1)

## Правило поиска

Искать **от задачи раздела**, а не от продукта: работа с таблицами → Google Sheets / MS / YCLIENTS; массовые операции → админки маркетплейсов; фильтры и срезы → метрики/BI. Большинство публичных баз — ecommerce, но сами паттерны повторяются в B2B.

## Источники

| Источник | Что там | Формат |
|---|---|---|
| Nielsen Norman Group (nngroup.com) | исследования UX, паттерны, гайдлайны | статьи, платно-частично |
| Baymard Institute (baymard.com) | ecommerce UX, каталог паттернов | гайдлайны, часть бесплатно |
| Хрусталёв — @hardclient (тг) + hardclient.com | русская база UX/UI, 5200+ гайдлайнов (в основном ecom) | посты, гайды |
| Human Interface Guidelines (Apple) | нативные паттерны iOS/macOS | документация |
| guides.kontur.ru | дизайн-система Контура | документация |
| material.angular.dev | Material-компоненты с примерами | документация |

Можно дополнять: открытые дизайн-системы (Material, Fluent, Carbon, Atlassian Design System), отраслевые каталоги.

## Как фиксировать находку

```
- Паттерн: <название и суть одним предложением>
- Где встречается: <продукт/источник>
- Чем применим у нас: <к нашему разделу/задаче>
- Ссылка: <url> · <дата>
```

## Промпт-рамка для поиска

```
Контекст: <продукт, раздел, сегмент>.
Проблема: <формулировка>.
Ищем: UX-паттерны и решения смежных систем для <задача раздела>.
Ограничения: только <список источников>; не предлагать готовые решения; каждый пункт — ссылка и дата.
Формат: таблица «паттерн | где | применимость | ссылка».
```
