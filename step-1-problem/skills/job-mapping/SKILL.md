# Джобы (JTBD): подготовка к исследованию

Первое действие исследования: письменно прописать **путь выполнения работы** по методике Jobs To Be Done. Из джобов собирается гайд для интервью (`interview-guide`). Эталон — обезличенный пример исследования: `step-1-problem/examples/primer-issledovaniya/`.

## Когда применять

- «нужно провести исследование — с чего начать», «собери джобы»;
- перед подготовкой гайда/интервью: понять, что и у кого спрашивать;
- для выбора концепции: сверить, какие работы закрывает каждая концепция.

## Пайплайн

1. **Источники:** исходники задачи целиком (презентация/постановка/переписка), заметки (`notes-search`), Jira, прошлые сессии. Конспект методики и шаблоны — `references/jtbd-method.md`.
2. **Main job** каждой стороны: «глагол + объект + пояснение» (пример: «Закупить продукты для кухни — с приемлемыми ценой, качеством и риском»).
3. **Путь (job map):** этапы выполнения работы. Пример (ресторан): потребность → поиск → сравнение и выбор → заказ → получение → оплата → оценка и пересмотр. Этапы = каркас блоков гайда.
4. **Таблица джобов:** `№ | сторона | сегмент/роль | джоба «Когда… — хочу… — чтобы…» | этап пути | релевантность проблеме (В/С/Н + привязка) | источник`. Сегменты/роли — из исходников, отдельные таблицы сегментов не делаем.
5. **Сохранить** в папку задачи: `tasks/<слаг>/01-проблема/исследования/jtbd-путь-и-джобы.md` + строка в `журнал.md`.

## Не в этом скилле

- **Гипотезы** и их приоритизация — следующий шаг процесса (скилл `iiko-hypotheses`); здесь только джобы, на основе которых собирается гайд.

## Правила

- Джоба — работа человека («прогресс»), не функция и не фича продукта.
- Релевантность каждой джобы привязывать к проблеме проекта (карточка проблемы, шаг 1).
- Факты и числа — со ссылкой на источник; неизвестное — «уточнить».
- Джобы — предположения о работах; финальные формулировки уточняются интервью (языком пользователей).
