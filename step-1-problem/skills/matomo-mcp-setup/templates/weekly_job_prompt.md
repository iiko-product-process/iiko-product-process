# Шаблон промпта для недельной cron-джобы (подставить SECTIONS и при необходимости период)

Сейчас <день недели>, <время> по Москве. Собери еженедельный отчёт Matomo по разделам: **SECTIONS**.

Доступ: мост Matomo уже настроен (инструменты `matomo_*`). Если инструментов нет — сообщи об этом и завершись.
Период: две последние полные недели, Пн–Вс — W1 (последняя завершённая) и W2 (предыдущая).

## 1. Данные

- `matomo_totals` с `period=week` и датой начала каждой недели → визиты, уникальные посетители, **пользователи (nb_users)**, действия, отказы, среднее время. (В недельном периоде `nb_uniq_visitors` и `nb_users` отдаются; в `period=range` — нет.)
- `matomo_daily` за диапазон `<W2start>,<W1end>` → день-к-дню.
- `matomo_devices`, `matomo_resolutions`, `matomo_hourly` с `period=week` по каждой неделе → устройства, разрешения, часы пик.
- По разделам: `matomo_pages` с `segment=pageUrl=@/<раздел>` (или `matomo_raw` с `Actions.getPageUrls`) — визиты и уникальные по каждому разделу за W1 и W2.

## 2. Блок «Страницы по разделам» — деревом (обязательно)

```
cd <путь_к_скиллу>/scripts && python3 pages_tree.py --date <W2start>,<W1end> --sections SECTIONS --depth 3 --limit 10 --sort v
```

Дополнительно можно прогнать по каждой неделе отдельно, чтобы показать динамику по ветвям.
Вывод вставить в сообщение **моноширинным блоком** (тройные обратные кавычки), дерево не переформатировать.
Помни: `uniq` в диапазоне — сумма дневных уникальных, оговори это в тексте.

## 3. Анализ

- WoW: W1 против W2 по разделам — визиты, уникальные, пользователи, действия; дать абсолютные числа и Δ%.
- День-к-дню: какой день просел/вырос и на сколько.
- Устройства/разрешения: сдвиги долей (сравнивать только сопоставимые диапазоны дней).
- Часы: пики и провалы по рабочему времени (таймзона инстанса!).
- По каждому разделу из SECTIONS: 1–2 вывода с цифрами + что посмотреть/сделать.
- Ничего не выдумывать: нет данных — писать прямо «данных нет» / «плагин не отдаёт».

## 4. Формат ответа

1. Шапка: «📊 Matomo: разделы SECTIONS · W1 <даты> vs W2 <даты>» + строка-резюме.
2. 4–8 пунктов-инсайтов; **между пунктами пустая строка** (двойной перевод строки), внутри пункта — заголовок + текст + буллеты с новой строки.
3. Блок «Страницы по разделам» — дерево в моноширинном блоке.
4. Если формируется HTML-вложение — путь к файлу и строка `MEDIA:<путь>`; имя файла с датой отчёта.
