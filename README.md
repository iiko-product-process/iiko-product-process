# Скиллы продуктового офиса iiko

Общая папка скиллов и наработок продуктового офиса iiko — единый источник, который шарится на команду.

## Что здесь

- `INDEX.md` — эталонный реестр всех скиллов (имя, шаг, путь, описание).
- `step-1-problem/` … `step-6-development/` — скиллы и наработки по каждому шагу процесса (скиллы + references/templates/scripts/examples/README).
- `tasks/` — шаблон задачи и сквозной скилл `task-workspace`.

## Как добавить скилл

1. Клонируй репозиторий, создай ветку `feature/<имя>`.
2. Добавь скилл в папку своего шага.
3. **Обязательно** добавь строку в `INDEX.md`.
4. Открой Pull Request в `main` — мёржится после апрува админа.

Прямой пуш в `main` запрещён.

## Статус

Снимок-объединение двух процессных репозиториев (`iiko-product-process-main` + `iiko-product-process`) на 19.10.2026. Исходные репозитории не менялись. Возможны дубли (например, шаг 4 в двух структурах — `prototyping-guide/04-агенты/` и `04-агенты/`) — их вычищает владелец.
