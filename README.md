# Скиллы продуктового офиса iiko

Общая папка скиллов и наработок продуктового офиса iiko.

## Две ветки

- **`main`** — общее: скиллы по шагам, реестр `INDEX.md`, шаблон задачи `tasks/_шаблон`.
- **`personal`** — личное: скелет для артефактов задач. У каждого сотрудника в форке — своё личное пространство.

## Как начать и как вносить правки

Полный процесс (форк, обновление `main`, личные задачи, PR) — в [CONTRIBUTING.md](CONTRIBUTING.md).

Коротко:

1. **Fork** → клонируй свой форк → `git remote add upstream https://github.com/erldur84-cyber/iiko-product-office-skills.git`.
2. Обновляешь скиллы: `git checkout main && git pull upstream main`.
3. Личные задачи — ветка `personal`.
4. Предлагаешь общий скилл — ветка `feature/*` → PR в `main` → мержит админ.

## Статус

Снимок-объединение двух процессных репозиториев (`iiko-product-process-main` + `iiko-product-process`) на 19.10.2026. Личные папки задач вынесены из `main` в ветку `personal`.
