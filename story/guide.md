# PB Task Writer — гайд для команды

## Что делает

Скилл-интервьюер для продукт-оунеров. Ты отдаёшь ему всю информацию по задаче (Jira, Confluence, макеты, текст, файлы) — он раскладывает её по единому шаблону, задаёт вопросы по недостающим блокам (с вариантами ответов) и создаёт в Jira Epic/Стори в одном стиле. В конце — отчёт: что заполнено, что пропущено, где разногласия и что уточнить. **Ничего не выдумывает.**

## Установка

1. Возьми файл скилла: `story/skill/SKILL.md` (в этом репозитории).
2. Положи его в скиллы Hermes, в категорию `productivity`, папкой `pb-task-writer`:
   - Windows: `C:\Users\<твой_логин>\AppData\Local\hermes\skills\productivity\pb-task-writer\SKILL.md`
   - Linux/macOS: `~/.hermes/skills/productivity/pb-task-writer/SKILL.md`
3. Перезапусти Hermes (или открой новую сессию), чтобы скилл подхватился.

В рабочем контейнере (Hermes на сервере, который ведёт Павел) скилл уже установлен в `/opt/data/skills/productivity/pb-task-writer/SKILL.md` — там он вызывается сразу.

## Как пользоваться

1. В чате с Hermes напиши `/pb-task-writer` (или просто «составь задачу по шаблону») и приложи всё, что есть по задаче.
2. Скилл разберёт вход и начнёт задавать вопросы по одному — с вариантами ответов и опцией «пропустить». Перед каждым вопросом показывает прогресс (`🔵 ~N%`).
3. Покажет структуру (эпик + стори) — подтверди «да».
4. Создаст задачи в Jira и выдаст ссылки + итоговый отчёт.

## Что важно

- Скилл **не выдумывает**: сомнительное помечает «нужно уточнить».
- Свободные/развёрнутые ответы сокращает до сути.
- Component и Labels спрашивает каждый раз (можно пропустить).
- HTML-прототип делает только если попросишь.
